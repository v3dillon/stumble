# Plan Personal Discovery locally without requiring Pods

Personal Discovery is User-scoped work rather than a synthetic Pod: the Home Node derives a minimized task-specific Discovery Plan from the private Taste Profile, Interest Seeds, Source Affinities, and locally matched public Stumble metadata, while an unattended Agent Harness receives only that plan. Profile-derived remote Index queries are forbidden, Pod discovery remains governed by Pod Packages, and both harness-owned scheduling and local Scheduler Adapters drive the same Discovery Task contract.
