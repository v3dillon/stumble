# Ingest external content only through Agent Harnesses

Stumble does not ship dedicated platform, feed, API, or browser Source Connectors. Agent Harnesses use their own browser, search, APIs, credentials, and scheduling under their own authorization, read Pod Packages and due Discovery Tasks, and submit structured provenance-bearing Candidates; Stumble validates, deduplicates, routes, curates, synchronizes, and ranks those submissions without receiving harness credentials or owning external access.
