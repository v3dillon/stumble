# Learn Personal Discovery only from User evidence

A User-submitted Content Reference creates a weak private Interest Seed, but an Agent Harness's autonomous discoveries never train the Taste Profile by themselves. Interest Seeds affect discovery only after independent User corroboration, may be omitted or retracted without deleting the Content Reference, and remain inspectable as aggregate evidence so Personal Discovery can learn without producing a self-reinforcing agent feedback loop.
