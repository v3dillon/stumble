# Limit open discovery abuse without identity gates

Publishing a discoverable public Pod requires no account, payment, proof-of-work, or centralized identity verification in the first release. Bootstrap Nodes contain Sybil amplification through per-network and per-Origin rate limits, reachability and manifest verification, stream and exploration caps, deduplication, and local quarantine, while each Home Node independently applies blocks and Trust Policy; signatures establish provenance but never personhood or quality.
