# Compose Feed Batches as a constrained blend

Feed Batches use configurable composition targets rather than a single global score order: by default roughly 70–80% highest-value subscribed content, up to 10% Exploration Items, up to 10% Old Gems, representation for eligible Priority Subscriptions, and per-Pod and per-source caps. Missing categories backfill from the next highest Attention Value items instead of leaving empty slots.
