# Admit verifiable public Pod Announcements openly

The sponsored Bootstrap Node accepts a public Pod Announcement without prior approval of its Origin Node when the signature, Origin identity, canonical public Pod URL, and current Pod manifest are verifiable and the submission satisfies bounded rate and size limits. Admission means only that the Pod is discoverable: it grants no endorsement, trust, quality score, or ranking advantage, all of which remain subject to each Home Node's local Trust Policy.
