# Domain Docs

Stumble is a single-context repository.

Before exploring or changing the domain:

- Read `CONTEXT.md` when it exists.
- Read relevant ADRs under `docs/adr/`.
- Use canonical terms from `CONTEXT.md` consistently.
- Surface conflicts with existing ADRs instead of silently overriding them.

`CONTEXT.md` is created lazily when the first domain term is resolved. `docs/adr/` is created lazily when a decision genuinely warrants an ADR.
